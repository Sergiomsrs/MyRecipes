# Agents

## Compilación y tests

Las compilaciones y pruebas de funcionamiento se realizan de forma manual por el desarrollador. No ejecutar `mvn compile`, `mvn test` ni comandos similares automáticamente.

- Para leer archivos usa la herramienta read, no cat/nl/for en bash.
- Una llamada de bash por comando, sin encadenar con && ni bucles.
- No intentes acceder a .idea/, archivos .env ni claves.
